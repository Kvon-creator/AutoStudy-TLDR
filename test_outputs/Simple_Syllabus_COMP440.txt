COMP440: Game Design
====================

Source: Simple_Syllabus_COMP440.pdf
Course prerequisites: COMP285

COURSE DESCRIPTION
This course will provide an introduction to current techniques used in game
design.Topics will include game engines, game mechanics, autonomous game agents, and
multi-player games. Prerequisites: COMP 285. (F;S;SS)
